📖 Documentation

                
                
Quick Start

                
    
                    
  1. This dashboard runs locally on http://localhost:5000
    2. 
                    
  2. It is NOT publicly accessible
    3. 
                    
  3. Your public site remains on S3/CloudFront
    4. 
                


                
Workflow

                
    
                    
  1. Edit Movies: Use the Movies Grid tab to filter and edit movie records
    2. 
                    
  2. Validate: The system prevents publishing without OTT or rating
    3. 
                    
  3. Enrich: Optionally run TMDB enrichment to fetch missing data
    4. 
                    
  4. Generate: Convert Excel to JSON format
    5. 
                    
  5. Preview: See what will appear on the public site
    6. 
                    
  6. Publish: Upload to S3 (CloudFront) to go live
    7. 
                


                
Validation Rules

                
    
                    
  • To publish: Must have OTT platform AND rating > 0
    • 
                    
  • Allowed statuses: published, review, draft
    • 
                    
  • Allowed OTT platforms: Prime Video, Netflix, Disney+ Hotstar, ZEE5, SonyLIV, SunNXT, Aha
    • 
                


                
Backups

                
    
                    
  • Automatic backups created before every edit
    • 
                    
  • Backups stored in: admin/backups/
    • 
                    
  • You can restore any backup from the Backups tab
    • 
                


                
Support

                
For issues or questions, check the console (F12) for error messages.
